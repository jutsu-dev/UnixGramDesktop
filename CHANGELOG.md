# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Заметки о выпусках лежат в [docs/releases/](docs/releases/).

## [Не выпущено]

Реорганизация кода и документации. Для пользователя ничего не меняется.

### Добавлено

- Документ [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): процесс и окна, модули Rust, контракт IPC, политика навигации, тестирование.
- Сценарий `npm run typecheck`.
- Проверки `cargo fmt --check` и `cargo clippy` в GitHub Actions.
- Файлы `.gitattributes` и `.editorconfig`.

### Изменено

- Код Rust разделён на модули: `config`, `state`, `preferences`, `theme`, `navigation`, `accounts`, `windows`, `tray`, `discord`, `shortcuts`, `connectivity`, `commands`. Файл `lib.rs` содержит только связывание.
- Сценарии, внедряемые в страницы сайта, перенесены в `src-tauri/src/webview/`.
- Интерфейс настроек разделён на разделы, компоненты, хуки и типизированные обёртки IPC.
- Команда `discord_presence` больше не принимает аргумент `clientId`: идентификатор приложения Discord задан константой в коде Rust.
- Поле `sessionStorage` в сведениях центра безопасности содержит строку «изолированные профили WebView2».
- Спецификация Playwright `desktop-shell.spec.ts` переименована в `settings.spec.ts`; спецификация `theme-matrix.spec.ts` удалена.
- Окно настроек загружает `index.html` без параметров запроса.
- Страница настроек не загружает шрифты из сети.
- Удалены зависимости, которые использовал только прежний интерфейс: `qrcode` и `@types/qrcode` (npm), `image`, `mime_guess` и `urlencoding` (Cargo). Основные версии остальных зависимостей не менялись.
- Зависимости обновлены в пределах прежних диапазонов версий: Tauri 2.11 → 2.12 (крейт и пакеты `@tauri-apps/api`, `@tauri-apps/cli`), плагины Tauri, `vite`, `storybook`.
- Заметки о выпусках приведены к единой схеме `docs/releases/vX.Y.Z.md`.
- README, CONTRIBUTING, SECURITY, PRIVACY и шаблоны GitHub переписаны в соответствии с новой структурой.

### Удалено

- Прежний собственный интерфейс клиента, который не загружало ни одно окно приложения, и связанные с ним команды Rust, типы, зависимости и тесты. Число команд IPC сокращено с 30 до 9.
- Вход по паролю и QR-коду через собственный код приложения и запись сессии в Диспетчер учётных данных Windows. Вход выполняется только на сайте UnixGram; сессия хранится в профиле WebView2.
- Файл `pnpm-lock.yaml`. Единственный менеджер пакетов — npm.
- Документ `docs/design-spec.md`, описывавший удалённый интерфейс.
- Файл `docs/security/sbom.cdx.json`. SBOM формируется для каждого выпуска по [чек-листу](docs/RELEASE-CHECKLIST.md#sbom).

### Исправлено

- Замечания clippy `collapsible_if` в коде Rust.

### Безопасность

- Обновлены `vite` и `storybook` в `package-lock.json`: устранены замечания `npm audit` уровней `critical` и `high`.

## [1.3.4] - 2026-10-16

Заметки о выпуске: [docs/releases/v1.3.4.md](docs/releases/v1.3.4.md).

### Добавлено

- Тема Mexican Pink в честь пользователя UnixGram `@cekc`. Тема работает с матовым и прозрачным стеклом, с отключённой прозрачностью и с компактными чатами.

## [1.3.3] - 2026-10-16

Заметки о выпуске: [docs/releases/v1.3.3.md](docs/releases/v1.3.3.md).

### Добавлено

- Два режима Liquid Glass: матовое и прозрачное стекло. Прозрачность можно отключить.
- Переходы к параметрам камеры, микрофона и звука Windows.
- Уведомление о результате загрузки файла.

### Изменено

- Кнопки, переключатели, горячие клавиши и аватары аккаунтов в настройках используют выбранную палитру.
- Стекло не размывает публикации, фотографии и видео.
- Значок в трее получает число непрочитанных чатов с сервера и сохраняет его при переходе в профиль.
- После восстановления связи страница не перезагружается без согласия пользователя.

### Исправлено

- Цвета светлой темы Daylight и стандартной темы со стеклом.
- Названия разделов профиля, поиска, студии и звёзд в Discord.
- Работа формы аккаунтов при повторных нажатиях и при сохранении настроек.

### Безопасность

- Обновлены `brace-expansion` и `source-map-js`: устранены известные уязвимости инструментов сборки.

## [1.3.2] - 2026-09-13

Заметки о выпуске: [docs/releases/v1.3.2.md](docs/releases/v1.3.2.md).

### Добавлено

- Темы Ocean, Rose и Forest. Всего тем — 12.
- Плавные переходы, настройка прокрутки к элементам и подчёркивание ссылок.

### Изменено

- Обновлены семь прежних палитр.
- Подписи в настройках стали короче. Кнопки доступны и в узких окнах.
- Начальный размер окна учитывает рабочую область основного монитора и масштаб Windows.
- Discord Rich Presence подключается автоматически на новых установках. Сохранённое отключение статуса не изменяется.
- Внешние HTTPS-ссылки открываются в браузере после подтверждения.

### Исправлено

- Повторное открытие UnixPlace из трея больше не сбрасывает текущую страницу.
- Темы не удаляют фон кнопок сайта.

## [1.3.1] - 2026-08-26

Заметки о выпуске: [docs/releases/v1.3.1.md](docs/releases/v1.3.1.md).

### Добавлено

- До трёх изолированных аккаунтов с переключением и удалением локальной сессии.
- Счётчик непрочитанных сообщений на значке в трее.
- Уведомления Windows без текста сообщений, имён и других личных данных.
- Автоматическое восстановление соединения после сбоя.
- Центр безопасности с состоянием сессий, сети, уведомлений и Discord Rich Presence.
- Глобальные сочетания `Ctrl+Shift+1…4` и дополнительные `Ctrl+Alt+U/M/G/S`.
- Discord Rich Presence по разделам без передачи содержимого аккаунта.

### Изменено

- Улучшена навигация в поиске, сообщениях и подарках профиля.

### Исправлено

- Вход по QR-коду больше не останавливается на истёкшем коде.
- Переход из UnixPlace возвращает пользователя в клиент.
- Нажатие на достижение открывает нужный профиль.
- Восстановлена привязка бота во вкладке со звёздами.
- Переключение и удаление дополнительных аккаунтов работает предсказуемо.
- Регистрация горячих клавиш не нарушает запуск, если отдельное сочетание занято другой программой.
- Окно настроек закрывается полностью и не остаётся скрытым в трее.

## [1.3.0] - 2026-08-23

Заметки о выпуске: [docs/releases/v1.3.0.md](docs/releases/v1.3.0.md).

Первый публичный выпуск.

### Добавлено

- Сайт UnixGram в окне приложения без замены его интерфейса.
- Лента, сообщения, профили, подарки и UnixPlace в отдельных окнах.
- Системный трей с быстрыми переходами.
- Девять тем, масштаб, полноэкранный режим и режим «поверх остальных окон».
- Discord Rich Presence с автоматическим переподключением.
- Отдельный профиль WebView2 для сохранения входа.
