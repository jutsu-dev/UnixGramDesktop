# Участие в разработке

UnixGram Desktop — неофициальный клиент с открытым кодом, с командой UnixGram не связан. Ошибки сайта (лента, сообщения, профили, подарки, UnixPlace) здесь не исправляются, пишите о них команде сервиса.

Участники соблюдают [кодекс поведения](CODE_OF_CONDUCT.md). Условия лицензий для вклада — в разделе [«Лицензия»](#лицензия).

## Ошибки и предложения

Ошибка: проверьте, нет ли похожей задачи в [Issues](https://github.com/jutsu-dev/UnixGramDesktop/issues), и создайте новую по шаблону «Сообщение об ошибке». Нужны версия клиента (раздел «Центр безопасности» в настройках), версия Windows, тема, масштаб, шаги воспроизведения, ожидаемый и фактический результат.

Предложение: шаблон «Предложение». Напишите, какую проблему оно решает, где должно появиться и что изменится для пользователя.

Cookie, токены и личную переписку не прикладывайте. Об уязвимостях пишите приватно, по [SECURITY.md](SECURITY.md). Остальные каналы: [SUPPORT.md](SUPPORT.md).

## Окружение разработки

```powershell
npm ci
npm run tauri:dev
```

Требования — в README, раздел [«Сборка из исходного кода»](README.md#сборка-из-исходного-кода). Менеджер пакетов только npm; `package-lock.json` меняется вместе с `package.json`.

Перед правками в коде Rust, политике навигации или контракте IPC прочитайте [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Требования к изменениям

### Общие

- Один запрос на слияние — одно изменение.
- Интерфейс и документация на русском, идентификаторы и комментарии в коде на английском.
- Тексты не должны намекать на связь с командой UnixGram.
- Зависимости обновляются в пределах текущей основной версии. Переход на новую обсуждается в отдельной задаче.

### Код Rust

- Код кладётся в модуль своей области. Карта модулей: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#модули-rust).
- Функции с `#[tauri::command]` лежат в `commands.rs` и только проверяют аргументы и вызывают другие модули.
- Логика без побочных эффектов — чистые функции с модульными тестами рядом.
- Константы (адреса, доверенные хосты, пределы) объявляются в `config.rs`.

### Интерфейс настроек

- Нативный код вызывается только через обёртки в `src/shared/ipc/`.
- Новый раздел настроек — отдельный компонент в `src/features/settings/sections/`.
- Страница должна работать в режиме предпросмотра, вне оболочки Tauri: так её открывают тесты Playwright.
- Страница ничего не загружает из сети, включая шрифты.

### Изменения, влияющие на безопасность

Тесты и обновление документации в том же запросе на слияние нужны, если меняются:

- политика навигации и список доверенных хостов (`navigation.rs`, `config.rs`);
- состав команд IPC, `src-tauri/build.rs`, `src-tauri/capabilities/settings.json`;
- сценарии в `src-tauri/src/webview/` и данные, которые ходят между страницей и нативным кодом;
- Content Security Policy в `src-tauri/tauri.conf.json`.

Изменение контракта IPC затрагивает `commands.rs`, список `invoke_handler` в `lib.rs`, `build.rs`, `capabilities/settings.json`, `src/shared/ipc/` и [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#контракт-ipc).

## Проверки перед запросом на слияние

Интерфейс настроек:

```powershell
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

Код Rust (нужен Visual Studio Build Tools):

```powershell
npm run tauri:check:windows
npm run tauri:test:windows
```

Если менялись темы:

```powershell
npm run test:native-e2e
```

Если менялись зависимости, пересоберите `THIRD-PARTY-NOTICES.md`:

```powershell
npm run licenses:notices
```

Локально Playwright использует установленный Google Chrome, в GitHub Actions — свой Chromium.

На каждый запрос на слияние workflow `Release quality` запускает `lint`, `typecheck`, `build`, `test:e2e`, сверку `THIRD-PARTY-NOTICES.md`, `npm audit`, проверки Rust (`cargo fmt --check`, `cargo clippy`, `cargo test`), Gitleaks, Trivy и `reuse`. Тесты `test:native-e2e` в него не входят.

## Запрос на слияние

1. Создайте ветку от актуальной `main`.
2. Внесите изменение и добавьте тесты.
3. Если изменение заметно пользователю или разработчику, добавьте запись в раздел «Не выпущено» в [CHANGELOG.md](CHANGELOG.md).
4. Обновите документацию, если меняются поведение, команды сборки или архитектура.
5. Заполните шаблон. Для изменений интерфейса приложите снимок окна без личных данных.

Сообщения коммитов — на английском в повелительном наклонении, например `Fix tray badge after account removal`.

Номер версии в запросах на слияние не трогайте: выпуски готовит владелец репозитория по [docs/RELEASE-CHECKLIST.md](docs/RELEASE-CHECKLIST.md). Как принимаются решения: [GOVERNANCE.md](GOVERNANCE.md).
