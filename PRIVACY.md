# Конфиденциальность

UnixGram Desktop — независимый клиент сообщества. Он не является официальным приложением UnixGram и не связан с владельцами сервиса.

## Какие данные обрабатываются

- Данные входа отправляются напрямую на `https://unixgram.com` по HTTPS.
- Пароль используется только для входа и приложением не сохраняется.
- Cookie сессии хранится локально в Windows Credential Manager.
- Настройки интерфейса хранятся локально в каталоге конфигурации приложения.
- Содержимое профиля, ленты, сообщений и подарков запрашивается напрямую у UnixGram. Собственный сервер UnixGram History для работы клиента не используется.
- Начиная с 1.3.2 Discord Rich Presence включён для новых установок. Сохранённое отключение не меняется. Передаётся факт использования клиента и, по выбору пользователя, название раздела. Имена и сообщения не передаются. Отключить статус можно в настройках клиента.

## Удаление данных

Команда выхода удаляет сохранённую сессию. После удаления приложения пользователь также может удалить запись `com.unixgram.desktop.community` из Диспетчера учётных данных Windows и локальный каталог конфигурации UnixGram Desktop.

## Ограничения

Обработка данных самим UnixGram регулируется правилами и политикой UnixGram. Клиент зависит от доступности и совместимости интерфейсов UnixGram.

Вопросы безопасности следует отправлять владельцу репозитория приватным способом, не публикуя токены, cookie и личную переписку.
