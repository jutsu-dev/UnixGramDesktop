# Поддержка

> [!NOTE]
> UnixGram Desktop — неофициальный клиент сообщества, с командой UnixGram не связан.

## Куда писать

| Повод | Канал |
| --- | --- |
| Вопрос или отзыв | [Telegram-канал UnixGram History](https://t.me/unixgramhistory). Сначала посмотрите [инструкцию по установке](docs/INSTALL-WINDOWS.md) и [существующие задачи](https://github.com/jutsu-dev/UnixGramDesktop/issues?q=is%3Aissue). |
| Ошибка клиента или установщика | [Issues](https://github.com/jutsu-dev/UnixGramDesktop/issues/new/choose), шаблон «Сообщение об ошибке». |
| Предложение | [Issues](https://github.com/jutsu-dev/UnixGramDesktop/issues/new/choose), шаблон «Предложение». |
| Уязвимость | Приватно, по [SECURITY.md](SECURITY.md). Публичную задачу не создавайте. |
| Нарушение кодекса поведения | Контакты в [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#приведение-в-исполнение). |

## Что указать

- версию клиента: настройки, раздел «Центр безопасности»;
- версию Windows;
- тему, масштаб, режим Liquid Glass;
- шаги воспроизведения, ожидаемый и фактический результат;
- воспроизводится ли ошибка на сайте UnixGram в обычном браузере;
- снимок окна без личных данных.

Cookie, токены и личную переписку не прикладывайте.

## С чем здесь не помогут

- Ошибки сайта UnixGram, которые воспроизводятся в обычном браузере: лента, сообщения, профили, подарки, UnixPlace.
- Вход, платежи и другие вопросы по аккаунту UnixGram. С ними обращайтесь к команде сервиса.
- Версии клиента старше [последней опубликованной](https://github.com/jutsu-dev/UnixGramDesktop/releases/latest).

Сроки ответа не гарантируются.
