# Локальные результаты

Каталог нужен только на компьютере разработчика. Git отслеживает в нём один этот README, остальное исключено в `.gitignore`.

| Путь | Содержимое |
| --- | --- |
| `releases/current` | Установщик и `SHA256SUMS.txt` выпуска, который проходит проверку. |
| `releases/archive` | Предыдущие локальные сборки. |
| `screenshots` | Снимки интерфейса и результаты визуальных проверок. |
| `security` | Отчёты локальных сканеров и SBOM. |

Подкаталоги создаются по мере необходимости. Как собирать установщик, контрольные суммы и SBOM: [чек-лист выпуска](../docs/RELEASE-CHECKLIST.md).

Установщики распространяются только через [Releases](https://github.com/jutsu-dev/UnixGramDesktop/releases) на GitHub.
