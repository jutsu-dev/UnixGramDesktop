# Локальные результаты

Эта папка используется только на компьютере разработчика:

- `releases/current` — установщик, который сейчас проверяют;
- `releases/archive` — предыдущие локальные сборки;
- `screenshots` — снимки интерфейса и визуальных тестов;
- `security` — отчёты локальных сканеров и SBOM.

Содержимое этих каталогов не публикуется вместе с исходным кодом. Публичные
установщики распространяются только через раздел Releases на GitHub.
