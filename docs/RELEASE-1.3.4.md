# UnixGram Desktop 1.3.4

## Mexican Pink

Новая тема в честь пользователя `@cekc` в UnixGram. Яркий розовый #E4007C, тёмные сливовые панели и светлый текст. Доступна всем в настройках клиента → «Оформление» → Mexican Pink.

Тема работает с матовым и прозрачным стеклом, отключённой прозрачностью и компактными чатами. Цвета кнопок ботов сохраняются.

## Также в этой версии

- Исправлены цвета Daylight и стандартной темы со стеклом.
- Кнопки и переключатели настроек используют выбранную палитру.
- Счётчик непрочитанных чатов получает данные с сервера.
- После восстановления связи страница не перезагружается автоматически.
- Исправлены названия разделов в Discord и повторные нажатия в форме аккаунтов.

## Установка

Скачайте **UnixGram-Desktop-1.3.4-x64-setup.exe** из файлов этого релиза. Контрольная сумма находится в **SHA256SUMS.txt**.

Установщик не подписан сертификатом Authenticode. Windows может показать неизвестного издателя. Не отключайте защиту системы.

## Проверки

Сборка, Rust-тесты, браузерные проверки настроек и CSS тем. Эти проверки не подтверждают доставку Windows-уведомлений, отображение Discord или переключение живых аккаунтов в установленном приложении.
