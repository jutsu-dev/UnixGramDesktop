# Установка неподписанной сборки

UnixGram Desktop пока выпускается без коммерческого сертификата Code Signing. Поэтому Windows может показать предупреждение SmartScreen и издателя «Неизвестный».

## Перед запуском

1. Скачивайте установщик только со страницы [GitHub Releases](https://github.com/jutsu-dev/UnixGramDesktop/releases).
2. Не запускайте копии из чатов, файловых обменников и сторонних сайтов.
3. Сверьте SHA-256 файла с суммой в описании релиза.

```powershell
Get-FileHash -Algorithm SHA256 ".\UnixGram.Desktop_1.3.0_x64-setup.exe"
```

## Если появился SmartScreen

1. Убедитесь, что имя файла и SHA-256 совпадают с релизом.
2. Нажмите «Подробнее».
3. Проверьте имя запускаемого файла.
4. Нажмите «Выполнить в любом случае» только после проверки суммы.

Самоподписанный сертификат не сделал бы сборку доверенной на чужом компьютере, поэтому мы не создаём ложное ощущение безопасности. Когда у проекта появится доверенный сертификат, новые релизы будут подписываться им.

Исходный код релиза доступен в репозитории. Сборку можно повторить самостоятельно по инструкции в [README](../README.md#сборка-из-исходников).
