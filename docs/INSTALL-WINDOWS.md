# Установка в Windows

> [!NOTE]
> UnixGram Desktop — неофициальный клиент сообщества, с командой UnixGram не связан и ею не одобрен.

## Требования

- Windows 10 или Windows 11, x64;
- Microsoft Edge WebView2 Runtime.

Установка идёт в профиль текущего пользователя. Язык установщика — русский или английский.

## Статус подписи

Установщик не подписан сертификатом Code Signing, поэтому Windows может показать предупреждение SmartScreen и издателя «Неизвестный». Самоподписанный сертификат не используется: на чужом компьютере он доверия не добавит. Подлинность файла проверяется по контрольной сумме SHA-256 из выпуска.

## Порядок установки

1. Откройте [GitHub Releases](https://github.com/jutsu-dev/UnixGramDesktop/releases). Не берите копии из чатов, файловых обменников и сторонних сайтов.
2. Скачайте `UnixGram-Desktop-<версия>-x64-setup.exe` и `SHA256SUMS.txt` из одного выпуска.
3. Вычислите контрольную сумму установщика:

   ```powershell
   Get-FileHash -Algorithm SHA256 ".\UnixGram-Desktop-1.3.4-x64-setup.exe"
   ```

4. Сравните результат со строкой из `SHA256SUMS.txt`. Если значения различаются, не запускайте файл.
5. Запустите установщик.

## Предупреждение SmartScreen

Сначала проверьте контрольную сумму. Затем:

1. Нажмите «Подробнее».
2. Проверьте имя запускаемого файла.
3. Нажмите «Выполнить в любом случае».

Отключать защиту Windows не нужно.
