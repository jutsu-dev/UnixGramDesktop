# UnixGram Desktop 1.3.2

Дата выпуска: 13 сентября 2026 года.

Выпуск добавляет три темы и обновляет окно настроек.

## Добавлено

- Темы Ocean, Rose и Forest. Всего тем — 12.
- Плавные переходы, настройка прокрутки к элементам и подчёркивание ссылок.

## Изменено

- Обновлены семь прежних палитр.
- Подписи в настройках стали короче. Кнопки доступны и в узких окнах.
- Начальный размер окна учитывает рабочую область основного монитора и масштаб Windows.
- Discord Rich Presence подключается автоматически на новых установках. Сохранённое отключение статуса не изменяется.
- Внешние HTTPS-ссылки открываются в браузере после подтверждения.

## Исправлено

- Повторное открытие UnixPlace из трея больше не сбрасывает текущую страницу.
- Темы не удаляют фон кнопок сайта.

## Установка

Файл установщика: `UnixGram.Desktop_1.3.2_x64-setup.exe`. Контрольная сумма SHA-256 приложена к выпуску.

Установщик не подписан сертификатом Code Signing. Windows может показать издателя «Неизвестный». Скачивайте приложение только со страницы выпуска и сверяйте контрольную сумму.

Пошаговая инструкция: [INSTALL-WINDOWS.md](../INSTALL-WINDOWS.md).

## Проверки

Пройдены 27 тестов Rust и 58 проверок настроек и тем. Вход, команды ботов, мини-приложения и подключение Discord в этом выпуске на реальном аккаунте не проверялись.
