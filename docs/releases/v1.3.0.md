# UnixGram Desktop 1.3.0

Первый публичный релиз UnixGram в отдельном приложении для Windows.

![Обложка UnixGram Desktop](https://raw.githubusercontent.com/jutsu-dev/UnixGramDesktop/main/docs/images/github-hero.png)

## Что внутри

- актуальный UnixGram без замены интерфейса сайта;
- лента, сообщения, профили, подарки и UnixPlace в отдельных окнах;
- системный трей с быстрыми переходами;
- девять тем, масштаб, полноэкранный режим и окно поверх остальных;
- Discord Rich Presence с автоматическим переподключением;
- отдельный профиль WebView2 для сохранения входа.

## Скачать

Ниже в блоке **Assets** скачайте:

`UnixGram.Desktop_1.3.0_x64-setup.exe`

Установщик пока не подписан коммерческим сертификатом. Windows SmartScreen может показать издателя «Неизвестный». Скачивайте приложение только из этого релиза и обязательно сверяйте SHA-256.

```text
7B4625E583335BD7378914C08F649306BB099878FD177876E05374949C64F0C3
```

Проверить файл можно командой:

```powershell
Get-FileHash -Algorithm SHA256 ".\UnixGram.Desktop_1.3.0_x64-setup.exe"
```
