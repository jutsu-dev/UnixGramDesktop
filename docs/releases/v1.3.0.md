# UnixGram Desktop 1.3.0

Первый публичный Windows-релиз клиента UnixGram History.

## Что внутри

- актуальный UnixGram в отдельном приложении без замены интерфейса сайта;
- системный трей с быстрым переходом к ленте, сообщениям, UnixPlace и настройкам;
- девять тем, масштаб, полноэкранный режим, окно поверх остальных и Liquid Glass;
- прокручиваемые настройки, которые сохраняются и применяются сразу;
- Discord Rich Presence с официальным логотипом UnixGram и автоматическим переподключением;
- сохранение авторизации в отдельном профиле WebView2.

## Установка

Скачайте `UnixGram.Desktop_1.3.0_x64-setup.exe` и запустите его.

Установщик пока не подписан платным сертификатом, поэтому Windows SmartScreen может показать неизвестного издателя. Скачивайте приложение только из этого релиза и сверяйте SHA-256:

`7B4625E583335BD7378914C08F649306BB099878FD177876E05374949C64F0C3`

Подробности: [инструкция по установке](https://github.com/jutsu-dev/UnixGramDesktop/blob/main/docs/INSTALL-WINDOWS.md).

UnixGram Desktop — независимый open source проект сообщества UnixGram History и не является официальным клиентом команды UnixGram.
