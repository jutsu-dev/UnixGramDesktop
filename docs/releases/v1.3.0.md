# UnixGram Desktop 1.3.0

Дата выпуска: 23 августа 2026 года.

Первый публичный выпуск: UnixGram в отдельном приложении для Windows.

## Добавлено

- Сайт UnixGram в окне приложения без замены его интерфейса.
- Лента, сообщения, профили, подарки и UnixPlace в отдельных окнах.
- Системный трей с быстрыми переходами.
- Девять тем, масштаб, полноэкранный режим и режим «поверх остальных окон».
- Discord Rich Presence с автоматическим переподключением.
- Отдельный профиль WebView2 для сохранения входа.

## Установка

Файл установщика: `UnixGram.Desktop_1.3.0_x64-setup.exe`.

Установщик не подписан сертификатом Code Signing. Windows SmartScreen может показать издателя «Неизвестный». Скачивайте приложение только со страницы выпуска и сверяйте контрольную сумму SHA-256:

```text
7B4625E583335BD7378914C08F649306BB099878FD177876E05374949C64F0C3
```

```powershell
Get-FileHash -Algorithm SHA256 ".\UnixGram.Desktop_1.3.0_x64-setup.exe"
```

Пошаговая инструкция: [INSTALL-WINDOWS.md](../INSTALL-WINDOWS.md).
