# UnixGram Desktop 1.3.1

Версия 1.3.1 делает ежедневную работу с UnixGram удобнее и надёжнее: несколько аккаунтов, системные уведомления, восстановление соединения и исправления найденных тестерами ошибок.

## Что нового

- до трёх изолированных аккаунтов с быстрым переключением и безопасным удалением локальной сессии;
- счётчик непрочитанных сообщений прямо на значке в трее;
- приватные уведомления Windows без текста сообщений, имён и других личных данных;
- автоматическое восстановление соединения после сбоя;
- центр безопасности с состоянием сессий, сети, уведомлений и Discord Rich Presence;
- глобальные сочетания `Ctrl+Shift+1…4` и запасные `Ctrl+Alt+U/M/G/S`;
- Discord Rich Presence по разделам без передачи содержимого аккаунта;
- улучшенная навигация в поиске, сообщениях и подарках профиля;
- проверки интерфейса в 120 сочетаниях тем, масштаба, размера окна и настроек.

## Исправлено

- вход по QR-коду больше не застревает на истёкшем коде;
- переход из UnixPlace возвращает пользователя в клиент;
- нажатие на достижение открывает нужный профиль;
- восстановлена привязка бота во вкладке со звёздами;
- переключение и удаление дополнительных аккаунтов работает предсказуемо;
- регистрация горячих клавиш не ломает запуск, если отдельное сочетание занято другой программой;
- отдельное окно настроек закрывается полностью, не оставаясь скрытым в трее.

## Скачать

Скачайте `UnixGram.Desktop_1.3.1_x64-setup.exe` из списка файлов ниже. Рядом приложен `SHA256SUMS.txt` для проверки целостности.

> [!WARNING]
> Установщик пока не подписан коммерческим Code Signing сертификатом. Windows SmartScreen может показать издателя «Неизвестный». Скачивайте приложение только из этого релиза и сверяйте SHA-256.

```powershell
Get-FileHash -Algorithm SHA256 ".\UnixGram.Desktop_1.3.1_x64-setup.exe"
```

Ожидаемая сумма:

```text
6a6f0b9f5558086684fdbb4164fc2671f20f52756c79ce539a83a91a381d5fc5
```
