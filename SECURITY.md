# Политика безопасности

> [!NOTE]
> UnixGram Desktop — неофициальный клиент сообщества. Уязвимости сервиса UnixGram и его сайта здесь не рассматриваются, о них пишите команде UnixGram.

## Поддерживаемые версии

Исправления выходят только для последней опубликованной версии.

## Сообщение об уязвимости

Не создавайте публичную задачу, если в отчёте есть способ обхода ограничений клиента, cookie, токены, персональные данные или содержимое сообщений.

1. Отправьте отчёт приватно: через «Report a vulnerability» на вкладке Security, если эта функция включена, иначе напрямую владельцу репозитория [jutsu-dev](https://github.com/jutsu-dev).
2. Укажите версию приложения, версию Windows, шаги воспроизведения, ожидаемый и фактический результат.
3. Не прикладывайте действующие секреты и данные реальных пользователей. Для демонстрации возьмите тестовый аккаунт.

Сроки ответа и исправления не гарантируются.

## Область действия

- обход политики навигации: недоверенный адрес открылся внутри окна приложения или внешняя ссылка открылась без подтверждения;
- доступ страницы сайта или стороннего содержимого к командам IPC;
- передача данных аккаунта (текст сообщений, имена, cookie) в нативный код, Discord или уведомления Windows;
- доступ одного слота аккаунта к данным другого;
- запись секретов в файл настроек или журналы;
- уязвимости в установщике и зависимостях, которые влияют на приложение.

## Модель доверия

- Внутри приложения открываются только `unixgram.com`, `www.unixgram.com` и `place.unixgram.com` по HTTPS на порту 443. Хост сравнивается точно. Адреса с именем пользователя или паролем, с другим портом и длиннее 8192 символов блокируются.
- Внешние ссылки открываются в системном браузере только после подтверждения. Всплывающие окна запрещены.
- Девять команд IPC доступны только локальному окну настроек. У содержимого сайта доступа к нативному коду нет.
- Вход выполняется на сайте UnixGram внутри WebView2. Приложение не получает пароль и не хранит сессию вне профилей WebView2. В Диспетчер учётных данных Windows сессия не записывается.
- Сайт UnixGram считается доверенным в пределах своего источника. Приложение внедряет в его страницы CSS темы и [сценарии](docs/ARCHITECTURE.md#внедряемые-сценарии-и-нативная-граница) и от уязвимостей самого сайта не защищает.
- Окно настроек загружает только содержимое из состава приложения и ограничено Content Security Policy.

Полное описание: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Распространение

- Установщик публикуется только в [GitHub Releases](https://github.com/jutsu-dev/UnixGramDesktop/releases) вместе с контрольными суммами SHA-256.
- Установщик не подписан сертификатом Code Signing. Как проверить контрольную сумму: [docs/INSTALL-WINDOWS.md](docs/INSTALL-WINDOWS.md).

## Автоматические проверки

На каждый запрос на слияние и каждое изменение `main` запускается workflow [Release quality](.github/workflows/release-quality.yml): `npm audit` с порогом `high`, Gitleaks (секреты) и Trivy (уязвимости, секреты и ошибки конфигурации уровней `HIGH` и `CRITICAL`).
