# Безопасность

## Поддерживаемые версии

Исправления безопасности выпускаются только для последней опубликованной версии UnixGram Desktop.

## Сообщение об уязвимости

Не создавайте публичную задачу, если отчёт содержит способ обхода входа, cookie, токены, персональные данные или содержимое сообщений. Отправьте владельцу репозитория приватный отчёт с версией приложения, шагами воспроизведения и ожидаемым результатом. Секреты и реальные данные пользователей к отчёту не прикладывайте.

## Модель доверия

- клиент принимает сетевые данные только от точных HTTPS-хостов `unixgram.com`, `www.unixgram.com` и `place.unixgram.com`;
- пароль не сохраняется;
- сессия хранится средствами Windows Credential Manager;
- установщик должен распространяться вместе с SHA-256;
- пока у проекта нет доверенного сертификата, неподписанный установщик нужно скачивать только из GitHub Releases и проверять по опубликованной контрольной сумме;
- после появления доверенного сертификата новые релизы должны подписываться им.
