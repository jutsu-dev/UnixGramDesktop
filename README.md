# UnixGram Desktop

Независимый Windows-клиент UnixGram от команды UnixGram History. Проект не является официальным клиентом и не связан с создателями UnixGram.

## Что работает в 1.3.0

- вход по QR, через официальный браузер или по логину/паролю;
- хранение сессии в Windows Credential Manager; пароль не сохраняется;
- автоматическое определение аккаунта после входа;
- живая лента `Для вас` / `Подписки` с cursor-пагинацией;
- создание публикаций с текстом и четырьмя изображениями через текущую сессию UnixGram;
- аватары, обложки, имена, username, отдельные verification/premium-статусы, фото, видео и подарки из ответа UnixGram;
- встроенный просмотр фотографий публикаций, профилей, сообщений и подарков с клавиатурной навигацией;
- реальные диалоги, история сообщений и отправка через текущую сессию UnixGram;
- реальные уведомления, сообщества, активность аккаунта, поиск и каталог подарков;
- пустые и ошибочные ответы показываются явно, без подстановки выдуманных данных;
- ссылки на профили `/u/{username}`, посты `/post/{id}` и подарки `/gift/{id}`;
- профиль, коллекция подарков, поиск, темы, настройки и Discord Rich Presence;
- обязательный экран входа перед загрузкой оболочки;
- сворачивание в системный трей вместо завершения по кнопке закрытия;
- частичная синхронизация: сбой каталога подарков не блокирует профиль и ленту;
- компактный Messenger-интерфейс без декоративных панелей, профиль в стиле UnixGram и 9 тем.

## Установка

1. Скачайте `UnixGram Desktop_1.3.0_x64-setup.exe` из `src-tauri/target/release/bundle/nsis/`.
2. Запустите установщик и выберите язык.
3. Откройте `Настройки → Сессия UnixGram` и войдите удобным способом.

Для запуска без установки есть portable `src-tauri/target/release/unixgram-desktop.exe`.

## Ограничение

Клиент использует текущие web-контракты UnixGram. Если сервис временно недоступен или изменит формат ответа, соответствующий раздел покажет ошибку и предложит повторить запрос; демонстрационные данные в установленной сборке не подставляются.

Перед публичным распространением ознакомьтесь с [политикой конфиденциальности](PRIVACY.md), [правилами безопасности](SECURITY.md) и [релизным чеклистом](docs/RELEASE-CHECKLIST.md). Сборка без действительной цифровой подписи Windows предназначена только для тестирования.
